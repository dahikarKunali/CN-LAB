# Experiment No. 6: DNS Packet Analysis (Windows / Ubuntu)

## Objectives
- To understand the working of DNS (Domain Name System) as an application layer protocol.
- To analyze DNS query and response packets generated by standard DNS diagnostic commands.
- To capture and inspect DNS protocol headers, transaction IDs, flags, and record fields using Wireshark and terminal utilities.

---

## Software / Tools Required
- Ubuntu Linux / Windows PC with Internet access
- Terminal (`bash`)
- DNS Utilities (`nslookup`, `dig`, `host`)
- Packet Analyzers (Wireshark GUI / `tshark` CLI)

---

## Step-by-Step Procedure & Commands

### Part A: DNS Query Commands
1. **Forward DNS Lookup (Resolving Domain to IPv4/IPv6 Addresses):**
   ```bash
   nslookup www.example.com
   ```
   - *Inspect:* Name server queried, Non-authoritative response, Resolved IP address (`93.184.216.34`).

2. **Reverse DNS Lookup (Resolving IP to Canonical FQDN):**
   ```bash
   nslookup 93.184.216.34
   ```
   - *Inspect:* PTR record resolving back to domain name.

3. **Querying Specific Resource Records (MX - Mail Exchanger):**
   ```bash
   nslookup -query=MX example.com
   ```
   - *Inspect:* Mail server hostname and preference priority values.

4. **Multi-Record Query (Google DNS):**
   ```bash
   nslookup www.google.com
   ```

## DNS Packet Header Structure
- **Transaction ID (16 bits):** Used to match a client's query with the corresponding server response.
- **Flags (16 bits):**
  - QR (Query=0 / Response=1)
  - Opcode (Standard Query = 0)
  - AA (Authoritative Answer)
  - TC (Truncated)
  - RD (Recursion Desired = 1)
  - RA (Recursion Available = 1)
- **Questions Count:** Number of queries in question section.
- **Answer RRs Count:** Number of resource records returned in answer section.

---

## Conclusion
- DNS operates at the Application Layer and primarily utilizes **UDP port 53** for low-latency queries.
- Wireshark and CLI utilities enable detailed examination of DNS query-response exchanges and address resolution mechanisms.

---

## How to Execute in Ubuntu Terminal

### Method A: Terminal Packet Capture with `tshark`
Open two terminal windows:

**Terminal 1 (Capture DNS traffic on UDP port 53):**
```bash
sudo tshark -i any -f "udp port 53" -Y "dns" -T fields -e frame.number -e ip.src -e ip.dst -e dns.id -e dns.qry.name -e dns.a
```

**Terminal 2 (Generate DNS Queries):**
```bash
nslookup www.example.com
nslookup 93.184.216.34
nslookup -query=MX google.com
```

---

### Method B: Graphical Packet Analysis with Wireshark
1. Launch Wireshark:
   ```bash
   sudo wireshark &
   ```
2. Select your active interface (e.g. `eth0` or `wlan0`) and click the blue **Start Capture** shark fin.
3. In terminal, generate DNS traffic:
   ```bash
   nslookup www.example.com
   ```
4. Stop capture, apply display filter `dns`, and inspect the Transaction ID, Flags, Questions, and Answers sections.
